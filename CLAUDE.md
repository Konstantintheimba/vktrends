# VK Trends — контекст проекта

Плагин WordPress `vk.fastfixsite.ru/public_html/wp-content/plugins/vk-trends`: дашборд трендов VK с личными кабинетами, автопостингом и стендом генерации изображений. Остальные файлы репозитория (`find_vk_groups.py` и прочее) к плагину отношения не имеют.

## Правила работы

- **Правки — сразу в папке плагина.** Без копий в scratchpad и без ожидания «ок» (пользователь 28.09.2026: «всегда пиши сразу в файл плагина!»). После правок — прогнать тесты и перечислить изменённое.
- **Архив не собирать.** Пользователь заливает папку плагина сам, `.zip` ему мешает.
- **Заливает и коммитит только пользователь.** Харнесс режет FTP и передачу учётных данных; проверять результат снаружи — сравнением первой строки `README.md` и md5 `assets/dashboard.js`.
- **Комментарии и интерфейс на русском.** Комментарий объясняет причину, а не пересказывает код.
- После правок — список изменённых файлов, отдельно новые: их легко пропустить при выборочной заливке.

## Устройство

Кабинеты: роль `vkt_member`, вход через VK ID, доступ после одобрения. Общее для сайта — сервисный ключ, приложение VK, ключи BFL и fal.ai, расписание сбора, журнал. Личное — пользовательский токен, ключ сообщества, группы, очередь публикаций, источники, ролики, товары. Константы из `wp-config.php` действуют только для хозяина сайта (`vkt_owner`). У cron нет пользователя, поэтому очередь публикаций выполняет каждое задание через `VKT_Account::act_as( автор )`, а сборщик — от имени хозяина.

Источники общие: сообщество обходится один раз, видимость даёт подписка (`vkt_subscriptions`), ролики — список `vkt_user_videos`.

Стенд генерации: `VKT_Flux` (api.bfl.ai) и `VKT_Fal` (queue.fal.run), поставщик выбирается значением модели вида `bfl:flux-2-pro`. Следующий шаг — третий поставщик «Свой сервер»: ComfyUI с Qwen-Image-Edit на арендованном GPU.

## Что проверено живьём и не надо перепроверять

- BFL не отдаёт правку фотографии человека, если на выходе открытый купальник: отказ и на входе (`Request Moderated`), и на выходе (`Content Moderated`), `safety_tolerance` до 5 не помогает. Генерация того же купальника с нуля проходит.
- Ключ сообщества VK не может прикладывать медиа никаким способом; фото грузит пользовательский токен, публикует ключ сообщества.
- Классический OAuth VK требует приложение из `dev.vk.ru`, вход через VK ID — приложение из кабинета VK ID.
