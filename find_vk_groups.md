# Ссылки на страницы VK через обычный поиск — без токена

Скрипт читает `vk.fastfixsite.ru/public_html/sourse.html` построчно, отправляет названия в поисковик и извлекает ссылки на страницы VK из заголовков выдачи. Нужны Python 3, интернет и `openpyxl` (уже установлен в текущем `python3` на этом компьютере). Авторизация, VK API и браузер не используются.

```sh
cd /Users/konstantinchikov/kostyan13/vktrends
python3 find_vk_groups.py
```

Для фоновой работы на этом Mac:

```sh
python3 vk_groups_background.py start
```

Терминал после запуска можно закрыть. Фоновый процесс продолжает сохранённый прогресс, после сетевых ошибок и ограничений повторяет запуск с паузой от 10 до 60 минут и завершается после обработки всех названий. Неоднозначные и ненайденные результаты остаются в отчёте; бесконечно повторно искать их он не будет. Во время работы `caffeinate` предотвращает автоматический сон Mac, а по окончании или остановке снимает это ограничение. Закрытие крышки и перезагрузку это не отменяет: крышку нужно оставить открытой; после перезагрузки снова выполнить `start`.

Состояние, просмотр лога и остановка:

```sh
python3 vk_groups_background.py status
tail -f output/vk-groups-web/background.log
python3 vk_groups_background.py stop
```

`Ctrl+C` при просмотре лога завершает только `tail`. Команда `stop` останавливает сборщик с сохранением отчётов; затем его можно продолжить через `start`. Повторный `start` не создаёт второй фоновый процесс. Блокировка папки результатов также защищает от одновременной записи отдельным ручным запуском `find_vk_groups.py`. Во время сбора `--export-only` в той же папке тоже заблокирован; Excel обновляет сам сборщик каждые 25 названий и при завершении попытки.

По умолчанию используется публичный встроенный поиск **Google CSE** (поисковый виджет Blackle). Скрипт сам получает его временные служебные параметры; вводить или регистрировать API-ключи не нужно. Они не сохраняются в файлы. Можно явно указать тот же способ:

```sh
python3 find_vk_groups.py --engine google
```

Предыдущая версия использовала HTML-выдачу DuckDuckGo и останавливалась на капче. Теперь используется другой интерфейс Google: новая версия получила реальные ссылки на `babyskris`, `delevsky_onlineschool` и `club226819393` из первых строк файла. Обычная страница `google.com/search` для автоматического поиска больше не используется.

Реальный запуск на первых 10 названиях завершился успешно: 3 совпадения, 5 названий с вариантами для проверки, 2 без ссылок в выдаче. Один сетевой сбой был обработан повтором в конце. Эти результаты уже сохранены; обычный запуск продолжит оставшиеся 1315 уникальных названий.

При временном сетевом сбое запрос повторяется до трёх раз. Если это не помогло, скрипт продолжает остальные названия и ещё раз пробует отложенные строки в конце. При трёх последовательных сетевых сбоях, капче или HTTP 429/403 останавливается и сохраняет уже обработанные результаты. Ошибка поиска не считается отсутствием группы. Работоспособность бесплатной выдачи зависит от Google и сети; полный проход всех 1326 строк пока не проверен.

Результат в `output/vk-groups-web/`:

- `vk_groups.xlsx`: лист **Ссылки** — строки `https://vk.ru/slug - название`, отдельные URL, заголовки выдачи, исходные строки и статусы; лист **Слаги** — только слаги без повторов; лист **Проверить** — неоднозначные совпадения и до пяти похожих вариантов. Для каждой исходной строки добавлена кликабельная ссылка на поиск в Google.
- `links.txt`: найденные ссылки с названиями.
- `slugs.txt`: только слаги без повторов, в порядке исходного списка.
- `progress.json`: результаты и поисковые запросы для продолжения.

Скрипт сначала ищет точную фразу на `vk.com`/`vk.ru`, затем название со словом «вконтакте». Для составных названий дополнительно пробует начало до `|` или `/`. Домен найденной ссылки приводится к `vk.ru`, слаг берётся из самой ссылки. Автоматически выбирается единственное совпадение названия с заголовком результата. Для названий от трёх слов допускается описание после полного названия. Регистр, пунктуация, внешние кавычки и HTML-сущности не мешают сравнению.

Поисковый заголовок — косвенное свидетельство: название может совпасть у разных страниц, а выдача может быть устаревшей. Скрипт отбрасывает ссылки на посты, видео, поиск, вход и числовые личные профили (`id123`), но отличить личную страницу с красивым адресом от сообщества по одной поисковой ссылке не всегда возможно. Такие результаты при необходимости нужно проверить вручную. Слаги не придумываются из названий.

Проверить первые пять строк:

```sh
python3 find_vk_groups.py --limit 5
```

Затем запустить без `--limit`. Прогресс записывается после каждого названия, отчёты — каждые 25 названий и при завершении, ошибке поиска или `Ctrl+C`. Пауза между запросами — 5 секунд; увеличить её можно через `--delay 10`.

Пересобрать отчёты из прогресса без запросов в интернет:

```sh
python3 find_vk_groups.py --export-only
```

Для другого файла или нового поиска, включая повторную проверку ненайденных названий:

```sh
python3 find_vk_groups.py /путь/к/названиям.txt --output output/vk-groups-new
```

Повторный запуск продолжает необработанные названия; сохранённые результаты повторно не запрашиваются. Для повторной проверки ненайденных и неоднозначных строк в той же папке:

```sh
python3 find_vk_groups.py --retry-unresolved
```

Ручные изменения Excel не импортируются, при следующей выгрузке отчёты перезаписываются. Исходный файл и плагин скрипт не изменяет. Прежний вариант DuckDuckGo оставлен только как дополнительный `--engine duckduckgo`; на этом соединении он требует капчу.

Описание интерфейса Google CSE: [Google Search Element](https://developers.google.com/custom-search/docs/element). Использование публичного виджета без пользовательского ключа также описано в [адаптере Google CSE проекта SearXNG](https://github.com/searxng/searxng/blob/master/searx/engines/google_cse.py).

На другом компьютере установить зависимость можно в отдельное окружение:

```sh
python3 -m venv .venv-vk-groups
source .venv-vk-groups/bin/activate
python3 -m pip install openpyxl
python3 find_vk_groups.py /путь/к/названиям.txt
```
